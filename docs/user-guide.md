# AI Usage Hub 사용 설명서

여러 AI 서비스의 구독료, 사용량, API 비용을 한 화면에서 보는 개인용 대시보드의 사용법입니다.

- 대시보드: Vercel에 배포한 주소 (예: `https://ai-usage-hub-ebon.vercel.app`)
- 백엔드: `https://ai-usage-hub-production.up.railway.app` (화면에서 직접 열 일은 거의 없습니다)

---

## 1. 처음 설정하기

처음 한 번은 아래 순서대로 설정하면 대시보드가 채워집니다.

| 순서 | 할 일 | 위치 | 참고 |
|---|---|---|---|
| 1 | 로그인 | `/login` | 2장 |
| 2 | 환율 방식 선택 | 설정 → 환율 | 7.3장 |
| 3 | 쓰지 않는 서비스 비활성화, 필요한 서비스 추가 | 설정 → 서비스 | 7.1장 |
| 4 | 구독 요금제 등록 | 설정 → 구독 정보 | 7.2장 |
| 5 | Claude Code·Codex를 쓰는 PC마다 기기 등록 + 에이전트 설치 | 설정 → 기기 관리, PC | 8장 |
| 6 | 그 밖의 서비스 사용량·비용 직접 입력 | 서비스 상세 | 5장 |

---

## 2. 로그인

1. 대시보드 주소로 접속하면 로그인 화면이 나옵니다.
2. 배포할 때 Railway에 설정한 `ADMIN_EMAIL`과 `ADMIN_PASSWORD`로 로그인합니다.
3. 로그인은 7일 동안 유지됩니다. 왼쪽 메뉴 아래 **로그아웃**으로 나갈 수 있습니다.

---

## 3. 화면 구성

왼쪽(휴대폰에서는 위쪽) 메뉴에서 화면을 이동합니다.

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 이번 달 요약과 서비스별 현황 |
| 비용 분석 | 월별 구독료와 API 비용, 12개월 추이 |
| 설정 | 서비스, 기기 관리, 구독, 환율, 표시·수집 설정 |

서비스 카드를 누르면 해당 서비스의 상세 화면으로 이동합니다.

## 4. 대시보드 보는 법

### 4.1 요약 4칸

| 항목 | 의미 |
|---|---|
| 월 구독료 합계 | 활성 구독의 월 환산 금액 합계. 연간 구독은 12로 나눕니다 |
| 연결된 서비스 | 활성 서비스 중 정상 데이터가 있는 서비스 수 / 활성 서비스 수 |
| 평균 사용률 | 한도 값이 있는 서비스의 사용률 평균. 한도 정보가 없으면 "—" |
| 이번 달 API 비용 | 이번 달 API 종량제 비용 합계(구독료 제외) |

금액 아래에 "일부 금액 환율 미설정"이 보이면 환율이 없어 USD 금액이 합계에서 빠진 것입니다. 7.3장에서 환율을 설정하세요.

### 4.2 서비스 카드

카드 오른쪽 위의 뱃지는 데이터가 어디서 왔는지 보여 줍니다.

| 뱃지 | 의미 |
|---|---|
| API | 서비스의 공식 API로 자동 수집 |
| CLI | PC 에이전트가 올린 값 (Claude Code·Codex 토큰) |
| 수동 | 직접 입력한 값 |

카드에 표시되는 상태는 다음과 같습니다. 이 대시보드는 **값을 모르면 0으로 표시하지 않고**, 이유를 보여 줍니다.

| 표시 | 의미 | 할 일 |
|---|---|---|
| 사용률 % 또는 사용량 숫자 | 정상 | — |
| 데이터 없음 | 아직 수집되거나 입력된 값이 없음 | 수동 입력 또는 에이전트 설치 |
| 수집 불가 | 해당 서비스가 이 지표를 제공하지 않음 | 정상적인 상태일 수 있음 |
| 수집 실패 (빨간 테두리) | 마지막 자동 수집이 실패함. 실패 사유가 함께 표시됨 | API 키와 권한 확인 |
| 비활성화된 서비스 (흐리게) | 설정에서 비활성화함 | 필요하면 다시 활성화 |
| (오래된 데이터) | 자동 수집 서비스가 수집 주기의 2배 이상 갱신되지 않음 | 수집 이력 확인 |

Claude Code·Codex 카드에는 **등록한 기기들의 이번 달 토큰 합계**가 표시되고, 그 아래에 기기별 값이 나옵니다. 기기 이름 앞의 점은 상태입니다.

| 점 | 의미 |
|---|---|
| 초록 | 온라인 — 최근 7분 안에 에이전트 신호가 있음 |
| 회색 | 오프라인 — PC가 꺼져 있거나 에이전트가 멈춤. 마지막으로 올린 값은 합계에 그대로 남음 |
| 빨강 | 폐기된 기기. 이미 올라온 이번 달 값은 실제 사용분이라 합계에 남음 |

카드 아래에는 이번 달 API 비용, 구독 갱신 D-day, 다음 한도 초기화 시각, 마지막 갱신 시각이 있는 경우에만 표시됩니다.

### 4.3 차트와 하단 정보

- **이번 달 비용 비중:** 서비스별 (월 구독료 + 이번 달 API 비용) 비율입니다.
- **최근 7일 API 비용:** 일 단위로 들어온 API 비용입니다. 월 단위로 직접 입력한 금액은 여기에 나오지 않습니다.
- **하단:** 다음 자동 수집까지 남은 시간과 적용 중인 환율(기준일·출처)을 보여 줍니다.

### 4.4 자동 갱신과 새로고침 버튼

- 대시보드와 서비스 상세 화면은 **1분마다 자동으로 갱신**됩니다. 다른 탭을 보다가 돌아오면 바로 갱신됩니다.
- PC 에이전트는 사용량이 바뀌면 1분 안에 올리므로, Claude Code·Codex 사용량은 보통 **1~2분 안에** 화면에 반영됩니다.
- **새로고침** 버튼은 서버의 API 자동 수집 커넥터를 즉시 실행하는 버튼입니다. 현재는 커넥터가 구현되지 않아 "자동 수집 대상 서비스가 없습니다"가 표시됩니다. 토큰 사용량 갱신과는 관계없습니다.

## 5. 서비스 상세와 직접 입력

서비스 카드를 누르면 상세 화면이 열립니다.

| 영역 | 내용 |
|---|---|
| 기기별 이번 달 토큰 사용량 | 기기마다 합계, 입력, 출력, 캐시 생성, 캐시 읽기, 마지막 업로드 시각 (Claude Code·Codex) |
| 최신 지표 (수동 입력·API) | 지표별 최신 값, 한도, 초기화 시각, 출처, 갱신 시각 |
| 수동 입력 / 보정 | 사용량과 월 비용 입력 |
| 비용 기록 | 최근 90일의 비용 기록 |
| 수집 이력 | 최근 수집 성공·실패 내역 |

### 5.1 사용량 입력

| 칸 | 예시 | 설명 |
|---|---|---|
| 지표 | `credits`, `requests`, `tokens` | 무엇을 셌는지. 입력해야 사용량이 저장됩니다 |
| 사용량 | `34` | 비워 두면 "수집 불가"로 기록됩니다 |
| 한도 (선택) | `100` | 넣으면 카드에 사용률(%)이 표시됩니다 |
| 단위 (선택) | `credits` | 카드에 숫자와 함께 표시 |

### 5.2 월 비용 입력

| 칸 | 설명 |
|---|---|
| 월 비용 | 그 달에 쓴 **API·종량제 비용**. 구독료는 넣지 않습니다 |
| 통화 | KRW 또는 USD |
| 월 | 비용이 발생한 달 |

같은 서비스·같은 달에 다시 입력하면 기존 값을 **덮어씁니다.** 합산되지 않습니다.

> 구독료는 여기에 넣지 마세요. 구독료는 설정의 구독 정보(7.2장)에 등록하며, 월 비용에 또 넣으면 두 번 계산됩니다.

**예시 — Cursor:** 지표 `credits`, 사용량 `34`, 한도 `100` → 카드에 34%가 표시됩니다. 요금제 금액은 구독 정보에 따로 등록합니다.

## 6. 비용 분석

1. 위쪽 월 선택에서 달을 고르고 **조회**를 누릅니다.
2. **구독료(월 환산)**와 **API 종량제 비용**이 따로 표시됩니다. 원래 통화와 환산 금액이 함께 나옵니다.
3. 아래에 환산 기준(환율, 기준일, 출처)이 표시됩니다.
4. **최근 12개월 API 비용 추이**는 서비스별로 쌓인 막대 차트입니다. 구독료는 이력이 없어 이 차트에 포함되지 않습니다.

서비스마다 측정 단위가 달라, 구독료 대비 사용량 비교는 참고용 추정치입니다.

## 7. 설정

### 7.1 서비스

- **비활성화/활성화:** 쓰지 않는 서비스를 비활성화하면 요약 계산에서 빠지고 카드가 흐리게 표시됩니다.
- **API 키:** 자동 수집 커넥터가 있는 서비스에만 입력 칸이 나옵니다. 키는 암호화되어 저장되고, 화면에는 끝 4자리만 보입니다. **현재는 커넥터가 없어 모든 서비스에 "자동 수집 커넥터 없음"이 표시됩니다.**
- **서비스 추가:** "서비스 추가"를 펼쳐 ID(영문 소문자·숫자·하이픈, 예: `copilot`), 이름, 제공사, 수집 방식을 입력합니다. ID는 나중에 바꿀 수 없습니다.

### 7.1.1 기기 관리

Claude Code·Codex를 쓰는 PC를 등록하는 곳입니다. 등록, 토큰 발급, 폐기 방법은 8장을 보세요.

### 7.2 구독 정보

| 칸 | 예시 |
|---|---|
| 서비스 | Claude Code |
| 요금제 | Max 5x |
| 가격·통화 | 100 USD |
| 결제 주기 | 월간 / 연간 |
| 갱신일 (선택) | 다음 결제일. 카드에 D-day로 표시 |

구독 정보는 서비스에서 자동으로 가져올 수 없으므로 직접 등록합니다. 요금제가 바뀌면 기존 항목을 **삭제**하고 새로 추가하세요.

### 7.3 환율 (USD → KRW)

| 방식 | 동작 |
|---|---|
| 자동 조회 (기본) | 6시간마다 갱신. 한국수출입은행 API 키가 서버에 설정돼 있으면 매매기준율을, 없거나 실패하면 ECB 기준환율을 씁니다. **지금 다시 조회** 버튼으로 바로 갱신할 수 있습니다 |
| 직접 입력 | 환율과 기준일을 입력. 자동 갱신이 덮어쓰지 않습니다 |

자동 조회가 실패하면 기존 환율을 그대로 쓰고, 실패 사유를 화면에 보여 줍니다. 현재 적용 환율과 기준일, 출처는 이 영역 위쪽에 표시됩니다.

참고: 지금은 지난달 금액도 **현재 환율**로 환산합니다.

### 7.4 표시 · 알림 · 수집

| 항목 | 설명 |
|---|---|
| 표시 통화 | 합계를 KRW 또는 USD로 표시 |
| 시간대 | "이번 달"과 "오늘"을 계산하는 기준 (기본 Asia/Seoul) |
| 알림 임계치 (%) | **알림 기능은 아직 없어서 값만 저장됩니다** |
| 수집 주기 (분) | 자동 수집 간격(15~1440분). 커넥터가 생기면 적용됩니다 |

## 8. PC 에이전트 (Claude Code·Codex 토큰 사용량)

Claude Code와 Codex는 사용할 때마다 PC에 세션 로그를 남깁니다. **PC 에이전트**가 이 로그를 1분마다 확인해 사용량이 바뀌면 서버로 올리고, 대시보드는 등록한 기기들의 값을 합쳐 보여 줍니다. 서버가 인터넷 너머의 PC에 직접 접속할 수는 없어서, PC가 서버로 보내는 방식입니다.

| 항목 | 내용 |
|---|---|
| 수집 대상 | Claude Code(`~/.claude/projects`), Codex(`~/.codex/sessions`) — 그 PC에 있는 것만 |
| 갱신 주기 | 사용량이 바뀌면 1분 안에 업로드, 바뀌지 않으면 5분마다 "살아 있음" 신호 |
| PC가 꺼져 있을 때 | 그 PC에서는 사용도 없으므로 빠지는 값이 없습니다. 다시 켜면 이번 달·지난달 누계를 다시 계산해 맞춥니다 |
| 지원 OS | Windows, macOS |
| 필요한 것 | 그 PC에 이 저장소(최소 `backend/collector` 폴더)와 [uv](https://docs.astral.sh/uv/) 설치. 백엔드 패키지는 설치하지 않아도 됩니다 |

### 8.1 기기 등록 (PC마다 한 번)

1. 대시보드 **설정 → 기기 관리**에서 기기 이름(예: 집 데스크톱, 맥북)을 입력하고 **기기 등록**을 누릅니다.
2. 노란 상자에 설치 안내가 나옵니다. **Windows / macOS** 탭 중 등록할 PC의 운영체제를 고릅니다(Mac에서 열면 macOS 탭이 먼저 선택됨).
3. 안내의 **1번 명령**(서버 주소와 기기 토큰 저장)과 **2번 명령**(에이전트 설치)을 각각 **복사**해서 등록할 PC에서 차례로 실행합니다.

| OS | 1번 명령이 하는 일 | 2번 명령이 하는 일 |
|---|---|---|
| Windows | PowerShell에서 사용자 환경변수 `AIHUB_URL`, `AIHUB_DEVICE_TOKEN` 저장 | `install-agent.ps1` → 작업 스케줄러에 "AI Usage Hub Agent" 등록 |
| macOS | 터미널에서 `~/.aihub/agent.env` 파일 생성(본인만 읽기 가능) | `install-agent.sh` → launchd LaunchAgent(`com.aihub.agent`) 등록 |

두 OS 모두 그 PC에 **이 저장소(최소 `backend/collector` 폴더)와 [uv](https://docs.astral.sh/uv/)** 가 있어야 합니다. 명령의 `<저장소 경로>`는 그 PC에 받은 저장소 위치로 바꿔서 실행하세요.

### 8.2 기기 토큰을 다시 확인하고 싶을 때

기기 토큰은 보안을 위해 **서버에 해시로만 저장되어 다시 볼 수 없습니다.** 대신 다음 두 가지를 쓸 수 있습니다.

- **설치 방법 보기:** 기기 관리 아래쪽의 "설치 방법 보기 (Windows / macOS)"를 펼치면 OS별 명령이 언제든 나옵니다. 토큰 자리는 `<기기 토큰>`으로 표시됩니다.
- **토큰 재발급:** 등록한 기기의 **토큰 재발급**을 누르면 새 토큰과 함께 해당 OS 명령이 다시 나옵니다. 그 PC에서 1번 명령(새 토큰 저장)과 2번 명령(재설치)을 다시 실행하면 새 토큰으로 바뀝니다. **기기와 사용량 기록은 그대로 유지**되고, 이전 토큰은 즉시 쓸 수 없게 됩니다.

### 8.2.1 에이전트 동작과 삭제

- 로그인할 때마다 **창 없이** 자동 실행되고, 오류로 멈추면 1분 뒤 다시 시작합니다.
- 실행 기록: Windows `%USERPROFILE%\.aihub\agent.log`, macOS `~/.aihub/agent.log`
- 삭제
  - Windows: `powershell -ExecutionPolicy Bypass -File .\collector\install-agent.ps1 -Uninstall`
  - macOS: `sh collector/install-agent.sh --uninstall`

### 8.3 동작 확인

1. 대시보드 **설정 → 기기 관리**에서 해당 기기가 **온라인**(초록 점)인지 봅니다.
2. Claude Code 또는 Codex 카드에 기기 이름과 이번 달 토큰 수가 나오는지 봅니다.
3. 아무것도 올라오지 않으면 `agent.log`의 마지막 줄을 확인합니다.

설치 전에 집계만 미리 보려면 다음을 실행합니다(서버로 보내지 않음).

```powershell
cd <저장소 경로>\backend
uv run --no-project python -m collector.agent --dry-run
```

### 8.4 숫자 읽는 법

- 카드의 숫자는 **입력 + 출력 + 캐시 생성 + 캐시 읽기** 토큰의 합계입니다. 캐시 읽기가 대부분을 차지해 숫자가 크게 보일 수 있습니다. 서비스 상세 화면에서 항목별로 나눠 볼 수 있습니다.
- Codex는 로그에 세션 누적값이 기록되므로 직전 값과의 차이를 사용량으로 계산합니다. 캐시에서 읽은 입력은 "캐시 읽기"로 따로 셉니다.
- 구독 한도 대비 사용률(%)은 로그에 없어서 계산하지 않습니다. Claude Code에서는 `/status`로 확인하세요.

### 8.5 기기를 바꾸거나 잃어버렸을 때

- **설정 → 기기 관리 → 토큰 폐기**를 누르면 그 기기의 에이전트는 즉시 업로드할 수 없게 되고, 에이전트는 오류를 기록한 뒤 종료합니다.
- 폐기 전에 올라온 이번 달 값은 실제 사용분이므로 합계에 남습니다.
- 토큰만 바꾸고 싶다면(유출 의심 등) 폐기 대신 **토큰 재발급**을 쓰세요. 기기와 기록이 유지됩니다.

### 8.6 주의할 점

- **휴대폰 앱, claude.ai 웹, ChatGPT 웹**에서 쓴 사용량은 PC 로그가 없어 포함되지 않습니다.
- 로그 형식은 공식 문서가 없는 내부 형식입니다. Claude Code나 Codex 업데이트로 형식이 바뀌면 에이전트를 고쳐야 할 수 있습니다. 특히 Codex 파서는 공개된 소스 코드 기준으로 만들었고, 실제 Codex 로그로는 아직 검증하지 않았습니다.
- 같은 PC에서 계정 여러 개를 번갈아 쓰면 계정별로 구분되지 않고 합쳐집니다.

## 9. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| "Application error: a server-side exception…" | 프론트엔드가 백엔드에 연결하지 못함 | Vercel 환경변수 `API_BASE_URL`이 Railway 주소인지 확인(끝에 `/` 없이) 후 **Redeploy**. 백엔드 `/health`가 열리는지 확인 |
| 로그인이 안 됨 | 이메일·비밀번호 불일치 | Railway의 `ADMIN_EMAIL`, `ADMIN_PASSWORD` 확인 |
| 금액이 "—"로 표시 | 데이터가 없거나 환율이 없어 환산 불가 | 구독·비용을 입력하거나 환율 설정 |
| "환율이 없어 일부 금액이 합계에서 제외" | USD 금액이 있는데 환율 미설정 | 설정 → 환율에서 자동 조회 또는 직접 입력 |
| Claude Code·Codex 카드가 "데이터 없음" | 등록한 기기가 없거나 에이전트가 아직 업로드하지 않음 | 8장. 기기 관리에서 온라인인지 확인 |
| 기기가 계속 오프라인 | PC가 꺼져 있거나 에이전트가 실행되지 않음 | `agent.log` 확인. Windows는 작업 스케줄러의 "AI Usage Hub Agent" 상태, macOS는 `launchctl print gui/$(id -u)/com.aihub.agent` 로 상태 확인 |
| `agent.log`에 "기기 토큰이 잘못되었거나 폐기되었습니다" | 토큰 오타, 재발급 후 PC에 반영 안 함, 또는 폐기된 기기 | **토큰 재발급** 후 1·2번 명령 다시 실행 (폐기된 기기는 새로 등록) |
| macOS `install-agent.sh`가 "기기 토큰이 없습니다" | 1번 명령(`agent.env` 생성)을 실행하지 않음 | 기기 관리의 macOS 탭 1번 명령 실행 후 다시 설치 |
| `install-agent.ps1`이 "환경변수가 없습니다" | 8.1 명령을 실행하지 않았거나 이전 창에서 실행 | 8.1 명령 실행 후 **새 PowerShell 창**에서 다시 실행 |
| 사용 중인데 값이 안 늘어남 | 로그 위치가 기본값과 다름 | 사용자 환경변수 `CLAUDE_PROJECTS_DIR` 또는 `CODEX_HOME`으로 위치 지정 후 에이전트 재시작 |
| 새로고침을 눌러도 바뀌는 게 없음 | 새로고침은 API 커넥터용인데 커넥터가 아직 없음 | 토큰 사용량은 에이전트가 자동으로 올리고 화면은 1분마다 자동 갱신됨 |
