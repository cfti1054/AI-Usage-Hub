## 1. 구현 완료

| 기능 | 내용 | 주요 파일 |
|---|---|---|
| 로그인 | 이메일·비밀번호 로그인 → JWT 발급. 비밀번호는 scrypt 해시 | `app/routers/auth.py`, `app/security.py` |
| 서비스 관리 | 목록·추가·수정·활성화/비활성화. 기본 서비스 4종(Claude Code, Codex, Cursor, Gemini CLI) 자동 생성 | `app/routers/services.py`, `app/seed.py` |

### 1.3 PC 에이전트 (`backend/collector/`)

- 등록한 PC에서 로그인 시 자동 시작(창 없음)되어 1분마다 Claude Code·Codex 로그를 집계합니다.
- 값이 바뀌면 업로드하고, 바뀌지 않으면 5분마다 온라인 신호만 보냅니다. 바뀐 로그 파일만 다시 읽습니다.
- 이번 달과 지난달의 월 누계·일별 합계를 보내므로, PC가 꺼져 있던 동안의 값도 다음 실행 때 맞춰집니다.
- 기기 토큰으로 인증하며, 토큰이 폐기되면 오류를 남기고 종료합니다.
- Windows는 `install-agent.ps1`(작업 스케줄러), macOS는 `install-agent.sh`(launchd)로 등록·삭제합니다. 표준 라이브러리만 써서 PC에 백엔드 패키지를 설치하지 않아도 됩니다.
- 설정은 환경변수 또는 `~/.aihub/agent.env`에서 읽습니다.
- Claude Code: 메시지 ID 기준 중복 제거. Codex: 세션 누적값의 차이로 계산, 캐시 입력 분리, 포크 세션의 재기록 이력 제외.

## 3. 알려진 제한 사항

- **서버 자동 수집 대상 없음:** API 커넥터가 아직 없어서 "새로고침" 버튼과 1시간 주기 수집은 가져오는 데이터가 없습니다. 토큰 사용량은 PC 에이전트, 그 밖의 값은 수동 입력으로 들어옵니다.
- **구독 정보 자동 조회 불가:** Claude Pro/Max 같은 개인 구독의 요금제·결제 정보를 가져오는 공개 API가 없어 직접 등록해야 합니다.
- **모바일·웹 사용량:** PC 로그가 없으므로 자동 수집할 수 없고 수동 입력만 가능합니다.
- **"실시간"의 범위:** 사용 후 약 1~2분 뒤 반영됩니다(에이전트 1분 주기 + 화면 1분 자동 갱신). PC가 켜져 있고 에이전트가 실행 중이어야 합니다.
- **같은 PC의 여러 계정:** 계정별로 구분되지 않고 합쳐집니다.
- **캐시 토큰:** 토큰 총합에는 캐시 읽기 토큰이 포함되어 실제 체감 사용량보다 크게 보일 수 있습니다.
- **한도 사용률:** 구독의 세션·주간 한도 사용률(%)은 로그에 없어 계산하지 않습니다.
- **백엔드 연결 실패 시 화면:** 백엔드에 연결할 수 없으면 프론트엔드가 안내 문구 대신 "Application error"를 보여 줍니다. 오류 안내 화면은 아직 없습니다.
- **스케줄러:** API 프로세스 안에서 실행되므로 Railway 레플리카를 1개로 유지해야 합니다.
